# 🏛️ ระบบศูนย์บัญชาการข้อมูลอาวุโส ตำรวจภูธรภาค 1 (ภ.1)

เว็บแอปพลิเคชัน Single Page Application (SPA) สำหรับตรวจสอบลำดับอาวุโสและคำนวณโควตาการแต่งตั้ง 33% ตามกฎ ก.ตร.

### ✨ ฟีเจอร์หลักของระบบ:
1. **บัญชีอาวุโสข้าราชการตำรวจ ภ.1 ครบ 3 ระดับ (266 นาย):**
   - รอง ผกก. (เลื่อนขึ้น ผกก. - เกณฑ์ 4 ปี)
   - สารวัตร สว. (เลื่อนขึ้น รอง ผกก. - เกณฑ์ 5 ปี)
   - รอง สว. (เลื่อนขึ้น สว. - เกณฑ์ 7 ปี)
2. **เครื่องคำนวณโควตาอาวุโส 33% อัตโนมัติ:**
   - ระบุจำนวนตำแหน่งว่างคาดการณ์ ระบบจะตัดยอดและไฮไลต์รายชื่อผู้การันตีได้รับแต่งตั้งทันที
3. **ระบบสืบค้นและตัวกรอง:**
   - ค้นหาด้วยชื่อ, ยศ, ตำแหน่ง, สภ.
   - กรองตาม 9 จังหวัดในสังกัดตำรวจภูธรภาค 1
   - กรองตามกลุ่มสายงาน (สอบสวน, สืบสวน, ป้องกันปราบปราม, อำนวยการ, จราจร)
4. **บัตรประวัติรายบุคคล:**
   - แสดงประวัติวันครองตำแหน่งย้อนหลัง, อายุตัว, อายุราชการสัญญาบัตร และปีเกษียณ
